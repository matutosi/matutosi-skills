# video-highlight

動画を指定の長さに縮める．**調べるのと切るのはスクリプト，どこを残すかは Claude が決める**．
スクリプトは `scripts/video_highlight.py` の1本で，`analyze` → (Claude が選ぶ) → `render` → `check` の順に使う．

## 準備

- Python 3.9 以降と `numpy`・`Pillow`．
- `ffmpeg`・`ffprobe` が PATH にあること．
- `faster-whisper`: 無ければ `python -m pip install faster-whisper`．
  初回はモデル (medium で約 1.5 GB) を Hugging Face から取ってくる (動画は送らない)．
  GPU が使えなければ CPU で動く (2分30秒の動画で約2分．`cublas64_12.dll` が無いと出るのは CPU に切り替えた知らせで，誤りではない)．
- (任意) NVIDIA の GPU があれば，`python -m pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"` で GPU で書き起こせる
  (2分30秒の動画で約10秒．Windows ではスクリプトが DLL の場所を自動で足す)．書き起こしの行に `on cuda` と出れば GPU で動いている．
- Windows でシンボリックリンクの警告を消すには，環境変数 `HF_HUB_DISABLE_SYMLINKS_WARNING=1`．

## 手順

作業用のディレクトリは **元の動画の隣に作らない**．ユーザに場所を聞くか，元の動画のフォルダの外 (一時フォルダなど) に `video_highlight/<動画の基幹名>/` を作る．
以下の `scripts/` は，このスキルのフォルダ (この SKILL.md のある所) の `scripts/` を指す．

1. **調べる**．

   ```
   python scripts/video_highlight.py analyze <動画> --out <作業ディレクトリ>
   ```

   - 英語の動画は `--lang en`，言語が分からなければ `--lang auto`．
   - 話していない動画 (野外の映像・音楽だけ) は `--no-transcribe` を付けると速い．
   - 書き起こしは `transcript.json` に残り，2回目からは使い回す (やり直すときは `--retranscribe`)．
   - 場面の切り替えが拾えないときは `--scene 0.05`，拾いすぎるときは `--scene 0.2`．

   出力:
   - `summary.md`: 区間の一覧 (id・開始・終了・長さ・種類・音量 dB・場面の切り替え・書き起こし)．**まずこれを読む**．
   - `sheet_NN.jpg`: 一定間隔の縮小画像を 5×4 枚に並べたもの．左上の数字が時刻．**映像の中身はこれで見る**．
   - `segments.json`: 上の元データ．

2. **残す区間を選ぶ** (Claude の仕事．下の「選び方」)．
   `<作業ディレクトリ>/selection.json` に書く．

   ```json
   {
    "target": 60,
    "note": "選んだ筋道を1行で",
    "keep": [1, 2, 6, {"id": 13, "start": 77.0}, {"start": 121.0, "end": 128.5}]
   }
   ```

   - `keep` には区間の id を並べる．区間の一部だけを使うときは `{"id": n, "start": 秒, "end": 秒}`，
     区間に関係なく時刻で指定するときは `{"start": 秒, "end": 秒}`．
   - 並べる順は問わない (時刻順に並べ直す．**順番の入れ替えはしない**)．隣り合う区間は1つにつなぐ．

3. **切ってつなぐ**．

   ```
   python scripts/video_highlight.py render --out <作業ディレクトリ>
   ```

   - 切り口は近くの無音へ自動で寄せる (言葉の頭・尻を切らないため)．このため合計は選んだ長さから ±1 秒ほどずれる．
   - 目標から 5% (または 2 秒) 以上ずれると警告が出る．そのときは `selection.json` を直してやり直す．
   - 出力は `<作業ディレクトリ>/<基幹名>_<目標秒>s.mp4` (H.264 + AAC)．名前は `--name` で変えられる．

4. **確かめる**．

   ```
   python scripts/video_highlight.py check <できた動画>
   ```

   できた動画を書き起こし直して表示する．**つなぎ目で言葉が切れていないか・話の筋が通っているかを読む**．
   映像も確かめるときは，できた動画に `analyze --no-transcribe` をかけてシートを見る．

5. **報告する**．出力のパス・長さ・残した区間と選んだ理由 (筋道)・落とした主な部分を書く．
   長さを変えた版 (60 秒と 30 秒など) を頼まれたら，`--name` を変えて `render` を2回回す (`analyze` は1回でよい)．

## 選び方

- **筋道を先に決める**．`summary.md` を通して読み，「導入 → 要点 → 結び」の流れを1行で書いてから区間を選ぶ (`note` に残す)．
  短くするほど要点を減らす．30 秒なら要点は1つか2つ．
- **文の途中で切らない**．whisper の区間は文の途中で分かれることがある (例: 「〜という図鑑を」「使っているものもあります」)．
  区間の末尾が言い切りになっていなければ，次の区間も残すか，両方を落とす．
- **落とすもの**: 言いよどみ・前置き・繰り返し・「たぶん」「分かりませんけど」のような留保・脇道．
- **残すもの**: 数字や結論を言う文・話題が変わる最初の文・最後のまとめ．
- **映像を見る**．スライドや場面の切り替え (`cut` 列の `*`) の直後は話題の始まりのことが多い．
  シートで，同じ画が長く続くところ (縮めやすい) と，動きのあるところ (残したい) を見分ける．
- **話していない動画**: 書き起こしが無いので，シートと音量 (dB) と場面の切り替えで選ぶ．
  動きのある場面を優先し，1区間は 3〜6 秒にとどめ，同じ画の区間を続けない．
- 目標の長さには **区間の足し引き** で合わせる．`summary.md` の `dur` を足して目標の ±3 秒に収める．
  合わないときは区間の一部 (`{"id": n, "start": …}`) で詰める．再生速度は変えない．

## 限界

- 選ぶ手がかりは書き起こし・音量・場面の切り替え・縮小画像だけ．表情や間の良し悪しは分からない．
- 区間は時刻順につなぐだけで，順番の入れ替え・字幕・BGM・映像のフェードはしない．
- つなぎ目は音だけ 0.04 秒でフェードする (プツッという音を防ぐため)．映像は切り替えでつなぐ．
