# 型 (レイアウトの選び方)

研究の筋に合う型を選ぶ．仕組みが示されていない研究を「中心と周り」の型に押し込まない．

## a. 流れ (既定)

左から右へ 3-5 コマを並べ，矢印でつなぐ．調査・実験・解析の研究の多くに合う．

```
┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐
│ 問い │ → │ 方法 │ → │ 結果 │ → │ 結論 │
└──────┘   └──────┘   └──────┘   └──────┘
```

- 横長 (330 × 132 mm) なら 4 コマ，正方形なら 2 × 2 か上から下へ 3 コマ．
- 結果のコマを少し広くする (図の中心は結果)．

## b. 対比

2 つの状態・処理・場所を左右に並べ，違いを見せる．「管理地と放棄地」「処理と対照」「過去と現在」．

```
┌─────────────┬─────────────┐
│   A (絵)    │   B (絵)    │
│  種数 25    │  種数 10    │
└─────────────┴─────────────┘
        結論 (1行)
```

- 左右で同じ要素を同じ位置に置く (見比べやすい)．
- 2 色に分け，凡例を兼ねる．

## c. 中心と周り

中心に主題 (生き物・現象) を置き，周りに要因や結果を配置する．
**要因と主題の関係が論文で示されているときだけ**使う．相関だけなら矢印を使わず，線か並置にする．

## d. 書籍 (読者の旅)

左に読者の困りごと，中央に本書で得られること (章を 3-5 個にまとめる)，右に読み終えたときの姿．

```
┌──────────┐   ┌───────────────────┐   ┌──────────┐
│ 困りごと │ → │ 本書で得られること │ → │ 読後の姿 │
│ (人物の絵)│   │  1 … 2 … 3 …       │   │ (人物の絵)│
└──────────┘   └───────────────────┘   └──────────┘
```

- 困りごとは読者のことばで (「企画書に何を書けばよいか分からない」)．
- 章の題をそのまま並べない．読者が覚えて帰ることを短く書く．
- 人物の絵は同じ人物にする (外部ツールに同じ人物の説明を毎回渡す)．
- 書名・著者名・出版社は使い道しだい (帯なら要らないことが多い)．

## 迷ったとき

- 結果が「差」なら b，「変化・つながり」なら a．
- 方法が新しいことが要点なら，方法のコマを大きくした a．
- 総説・書籍なら d か，項目を並べた a．
