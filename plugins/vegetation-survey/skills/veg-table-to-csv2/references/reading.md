# 読み方の手引き (veg-table-to-csv2)

組成表の画像を読んで転記 (`transcripts/Tab.NNN/`) を作るときの決まりです．
**転記は印字のとおりに書きます．値を直すのは決定の段 (規則 D・T) の仕事で，読む人はしません**．

読む手順そのもの (準備・見渡す・切り分ける・表頭・本体・1 回出現と注記・検算) と道具 (`crop.py`・`marks_grid.py`・`check.py`・`shift_check.py` など) は，今のスキル `veg-table-to-csv` のものを使います．
読むもの: `veg-table-to-csv/SKILL.md` の 3〜7 節，`references/transcript-format.md`・`reading-pitfalls.md`・`table-structure.md`．
**同じ SKILL.md の 8.4・8.5 節の規則 (X1〜X57) は，下の「当てる」に挙げたものだけを当てます．**

## 1. 印字のとおりに書く

- 字は見えたとおりに書きます．誤植と分かっても直しません (学名・和名・地名・県名の記号・方位・年・高さの小数点・常在度の書式も)．
  - 例: 調査区数 8 の列の `1(+)` は `1(+)` のまま．`I(+` (括弧の欠け) も `I(+` のまま．県名の記号 `0` も `0` のまま．`'70` も `'70` のまま．
- 1 回出現の種は，印字の段落 (`in N:`) のまま書きます．見出しが欠けていても，番号がずれていそうでも，種数に合わせて動かしません．
- 階層は印字のまま書きます (`B2` を `B` にしない．`k` を `K` にしない．表頭に無い記号もそのまま)．印字の無い階層は空欄です．
- 「同左」「左同」「- -」「Y*」も印字のまま書きます．
- **例外: 表頭の項目名** (`item_ja`) は値ではなく行の見出しなので，和文が誤植で独文と食い違うときは独文に合わせて書き，印字を note に残します (調査区数の行の和文が「出現種数」と誤植され，独文が `Zahl d. Aufnahmen` の表．誤植のままだと道具が調査区数を種数として照合する)．
- 注記の地点の番号 (`25-27`・`26:34`) も印字のまま書きます．表の地点数を超えても直さず，表の右端に列の続きが無いことを確かめて，note に事実を書きます．
- 出現種数が合わなくても，値や地点を変えません．合わないことは決定の段が矛盾 (N) として拾います．
- ほかの表・ほかの資料・古い転記を見て値を決めません．**古い置き場の転記や CSV は開きません** (読み直しの結果を，あとで古い転記と比べるため)．

### 表頭・注記の項目名 (2026-11-17 ユーザ決定)

項目名 (`item_ja`) は，できるだけ次の決まった名で書きます．別の言い方の印字は，決まった名で書いて印字を note に残すか，印字のまま書きます (決定の段の D32 と対応表 `item_names.tsv` がそろえる)．

| 決まった名 | よくある別の言い方 |
|---|---|
| 調査番号 | 調査票番号・調査区番号 |
| 群落区分・下位群落区分 | 群落記号・群落区分記号 (同じ表に別の行としてあれば，そのまま書き分ける) |
| 調査地・調査地 (県名) | 調査地(県名)・調査地 (県)・調査地名 (県名) |
| 調査年月日 | (月日だけの印字は「調査月日」のまま) |
| 調査面積・海抜高度・方位・傾斜 | 海抜高・海抜・標高 |
| 高木第1層の高さ・高木第1層の植被率 | 高木第 1 層・高木第一層・高木第1層植被率 (層の名は 高木層・高木第2層・亜高木層・低木層・草本層・蘚苔層) |
| 植生高・植被率 | 植生の高さ・群落高・全植被率 |
| 出現種数・平均出現種数・調査区数 | |

## 2. 当てる読み方の決まり

書き写し方の決まりで，決定の段に移していないものです．当てたら note に規則の番号を残します．

| 規則 | 中身 |
|---|---|
| X7 | 値の字がかすれても読みが 1 つに決まれば，その読みで書く |
| X10 | 名だけで値の無い行は残して全地点を出現なし．1 回出現で値の無い種は `K +` |
| X11 | 点 (`・`) で非出現を書く表の，点も値も跡も無い空欄は点の落ちとみる (条件は今の SKILL.md．同じ行の左右と同じ列の上下に点か値があるとき)．空欄が 2 つ以上続くときは当てず，`・?` にして確認に出す．表の端の行・列 (片側の隣が無い) では，ある側の隣がすべて点か値なら当ててよい (2026-11-17 ユーザ決定) |
| X12 | 表頭の値の下線は，凡例が無ければ note に `N: 下線` とだけ書く |
| X16 | 小文字の `v` は印字のまま `v` |
| X26 | 値のセルの短い横棒だけ (`-`) は `+` と書き，note に `N: 印字は横棒だけ (-)．+ とした (規則 X26)` (決定の段の D29 がこの note を見る) |
| X27 | `++` は `+` (note に印字) |
| X29 | 常在度の列の小文字 `v` は `V` (note に印字) |
| X36 | 種名 (階層の字) の下線に対応する値の下線が無いときは，下線の無い値として扱う |
| X48 | `+` に点が重なる・`+.` は `+` |
| X49 | 折り目・よごれの線が重なるだけで読みが 1 つに決まれば，その読みで書く |
| X52 | 学名・和名の `?` は印字のまま |
| X53 | 1 回出現の名の無い値 (`K-+` だけ) は種に含めず note に残す |
| X56 | 白抜きの丸は `○` のまま (小文字の `o` にしない) |

- 下線・二重下線・波線は，見えたとおりに note に書きます (`印字は S,K (S に下線)`・`N: 下線`・`N: 二重下線`)．どの階層の値かは決定の段 (T01) が決めます．
- 行と行の間の線は，上の行の値の下線とみて書きます．括弧書きの種名に下線があり値にも対応する下線があるときは，下線の値を括弧の中の種の行へ分けて書きます．
- 同じ種の印字が 2 回ある (本体の 2 か所・本体と 1 回出現など) ときは，2 回とも書きます．

## 3. 当てない決まり (決定の段が当てる)

今の SKILL.md の次の規則・指示は，**読むときに当てません**．印字のまま書けば，決定の段が当てます．

- 常在度の書式 (X8・X8 (i)・X8 (ii)・X25・X57・出現地点数が調査区数を超える)．
- 種名の誤植・和名優先 (X20・X22)．地名の誤植 (X2・X21・X54)．県名の記号 (X1・X33・X44)．
- 年・日付 (X5・X19・X34・X55)．方位の字 (X31・X45〜X47)．高さの小数点 (X32)．単位 (X4)．
- 階層の直し (X14・X17・X18・X23・X24・X37・X42・X43・X51)．
- 1 回出現の見出しのずれ (X35．2026-11-04 の「同じ番号が続く見出しの読み替え」も)．
- 2026-11-04 の「聞かずに直す印字の誤り」のうち値を直すもの (中黒の落ちを補う・算用数字をローマ数字に・出現地点数を調査区数に)．
- 種数が合わないときの notes.tsv の「出現種数の印字」の行は足しません．

## 4. ユーザに聞くもの (`user_review.tsv`)

**画像の問題で読みが決まらないものだけ**を積みます (かすれ・重なり・判読できない字・印の有無が分からない)．`kind` は `A. 読めない値`・`A. 常在度の値`・`A. 字` のどれかです．
転記には推定の読みに `?` を付けて書き，`status=check` にします．

文脈からおかしいもの (種数が合わない・表頭と注記の食い違い・誤植の疑い・下線の対応の推定・見出しの欠け) は聞きません．決定の段が矛盾として拾い，規則で決めます．
気づいたことは転記の note に事実として書いてよい (`見出しが欠けている`・`和名は誤植の疑い`)．

## 5. 終わりの確かめ

今の SKILL.md の 7.4 節 (done にする前の確かめ)・7.6 節 (列ごとの 1 行ずれの点検) を行います．
種数の差のある地点は画像で読み直します．**読み直しても合わなければ，そのまま done にします** (差を log に書く)．合わせるために値を変えません．
