# 組成表の構造と記号

読む前に知っておくこと．この文書だけで足りるように書いてある．

## 1. 1 枚の組成表の部品

```
Tab. 34. ハマゴウ―アキグミ群落 ...        ← 表題 (番号・和文・独文/ラテン語)
                 ┌───── 表頭 (地点の情報) ─────┐
Spalte:          群落区分    │ 1 │    2    │  3  │    ← 群落の区分 (列のまとまり)
Laufende Nr.:    通し番号    │ 1  2  3  4  5 ...  │    ← 地点の番号 (Lfd. Nr.)
Feld-Nr.:        調査番号    │ SS SS ...          │    ← 2 段に割れる (SS / 67)
Größe d. ...     調査面積    │ 2  2  2  9 ...     │
Artenzahl:       出現種数    │ 7  7  7  8 ...     │
─────────────────────────────┼────────────────────┤
Trennart d. Ges.: 群落区分種  │                    │    ← 見出しの行 (種群の名前．値なし)
  Elaeagnus umbellata  アキグミ  S │ 5・4 4・4 ・ ・ +・2 │ ← 種の行: 学名・和名・階層・値
出現1回の種 Außerdem je einmal in Lfd. Nr. 1: ...        ← 1 回出現の種 (文章)
Lage d. Aufn. 調査地: Lfd. Nr. 1, 3: ... (6. Juli 1983)   ← 注記 (調査地・調査日・出典)
```

- **列 = 地点** (調査区・スタンド)，**行 = 種** (＋階層)，セル = その地点での量．
- 表側 (左) は **学名** (ラテン語．斜体)・**和名** (カタカナ)・**階層** の順が多い．
  和名だけ・学名だけの表もある．階層の列が無い表もある (草本群落など)．
- 表頭の項目名は**独文と和文の 2 つ**が並ぶ (`Höhe ü. Meer (m)` と `海抜高`)．
  CSV には両方を書く．単位は独文の括弧の中にあることが多い．
- **見出しの行** (`Kennart d. Ass.: 群集標徴種`・`Begleiter: 随伴種` など) は，
  種をまとめた著者の解釈で，データではない．CSV では種の行の `group_ja`・`group_de` に写す．
  2 行にまたがることがある (`群集標徴種` / `および区分種`)．
- 表のいちばん上の行は，種ではなく見出しであることが多い．

## 2. 表頭の項目 (よく出るもの)

| 和文 | 独文 | 値の例・注意 |
|:---|:---|:---|
| 通し番号 | Laufende Nr. / Lfd. Nr. | 1, 2, 3 … **地点の鍵** (`plot`) |
| 調査番号 | Feld-Nr. | `SS` / `67` と 2 段に割れる → `SS-67` |
| 調査年月日 | Datum d. Aufnahme | `'83` / `8` / `3` と縦に 3 段 → `1983-08-03`．年が見出しにあることも (`Datum d. Aufn. (1983)`) |
| 調査地 (県名) | Ort d. Aufn. (Signal d. Präf.) | `K` `M` `W` などの記号．凡例は注記にあることが多い．記号のまま書く |
| 調査面積 | Größe d. Probefläche (m²) | |
| 海抜高 | Höhe ü. Meer (m) | 3〜4 桁 |
| 方位 | Exposition | `N` `SE` `—` |
| 傾斜 | Neigung (°) | |
| 植生高 | Höhe d. Vegetation (cm) | |
| 植被率 | Deckung d. Vegetation (%) | |
| 高木第 1 層の高さ・植被率 | Höhe / Deckung d. Baumschicht-1 | 高木第 2 層 (`-2`) も．m と % |
| 低木層の高さ・植被率 | Höhe / Deckung d. Strauchschicht | |
| 草本層の高さ・植被率 | Höhe / Deckung d. Krautschicht | `0.5` の小数点に注意 |
| コケ層の植被率 | Deckung d. Moosschicht | |
| 出現種数 | Artenzahl | **検算に使う** (`scripts/check.py`) |
| 群落区分 | Spalte | `1` `2` `3` や `a` `b1` `b2`．列のまとまりを囲む枠 |

- `—` `-` は「無い・測っていない」．値は `-` にそろえ，推測で 0 にしない．
- **表頭が文章の形**の表もある (地点が 1〜数個の表に多い)．
  `Feld-Nr. 調査番号：SO-216, Größe d. Probefläche 調査面積：100m². …` と流し込まれている．
  項目ごとに分けて，表の表頭と同じ行の形で書く (`plot` は 1)．
  `方位, 傾斜：S 35°` のように 2 項目で 1 つの値を持つ形は，2 行に分ける．

**出現種数の数え方は表によって違う**．多くの表は 1 回出現の種を含むが，本体の種だけを数え，1 回出現の種を含まない表もある．
全種で数えると多い側へずれ，その差が地点ごとの 1 回出現の種の数に近ければ，こちらの型．
ほかに，次の型がある．どれも**種数に合わせて値を足さない**．理由を reading_log.md に書いて印字のまま残す．

- 本体と 1 回出現に同じ種が載り，2 つと数えている．
- 同じ種が 2 つの見出しに載り，別に数えている (`check.py` の「見出し × 種 × 和名」と合う)．
- 一部の地点だけコケ類を数えていない．差が +3〜4 なら，コケ類を除いた数と比べる．
- 維管束とコケの 2 行に分かれている (`check.py` は 2 行の合計と比べる)．
- 群の中で昇順に並ぶ表で，1 地点だけ大きい．印字の誤植が疑える．
- 地点どうしで種数が入れ替わって見える (`check.py` の `[手がかり]`)．

表頭の値の行の並びが，左の項目名の並びと合わない表もある．値の性質 (海抜は群の中で昇順など) で割り当て，`status=check` にする．
調査年月日が表頭に無い表は，注記の括弧の中の日付を notes.tsv に書く．

## 3. セルの値

### 被度・群度

「被度・群度」の順に，`・` (または `.` `-`) で区切って書かれる．

| 印字 | cover | sociability | 意味 |
|:---|:---|:---|:---|
| `4・2` | `4` | `2` | 被度 4，群度 2 |
| `+・2` | `+` | `2` | 被度 +，群度 2 (**実データで最も多い**) |
| `+` | `+` | `1` | **`+・1` の省略形**．群度 1 だけが省略される |
| `r` | `r` | `1` | `r・1` の省略形 |
| `・` だけ・空欄 | (行を書かない) | | **非出現** |
| `(+)` | `+` | `1` | 括弧付き．`note` に `括弧付き` と書く |

- 被度は `5 4 3 2 1 + r`，群度は `1`〜`5` しかない．それ以外に見えたら読み違いを疑う．
- 被度の意味: 5 = 75-100%，4 = 50-75%，3 = 25-50%，2 = 10-25%，1 = 1-10%，+ = 1% 未満，r = ごくまれ．
- **下線の付いた値**がある (`1・2` の下に線)．意味は資料の凡例に従う．
  凡例が無ければ `note` に `下線` と書いて値はそのまま．

### 常在度表 (列が地点ではなく群落)

表の列が「群落」で，セルが `IV` や `IV(+-3)` の表 (常在度表・総合常在度表)．

| 印字 | constancy | cover | sociability |
|:---|:---|:---|:---|
| `V` | `V` | | |
| `IV(+-3)` | `IV` | `+-3` (被度の範囲) | |
| `2(3-4)` (単独地点の列) | | `2` | `3-4` (群度の範囲) |
| `2(3-4)` (調査区の少ない列) | `2` (出現地点数) | `3-4` (被度の範囲) | |
| `+(1)` | `+` | `1` | |

- **1 つの表に，群落の要約列と単独地点の列が混ざる**ことがある．どちらも `頭(括弧)` の形．
  頭がローマ数字なら常在度，算用数字なら被度．**列ごとにどちらかにそろう**ので，
  迷ったセルは同じ列のほかのセルの多数決で決める．
- **調査区の少ない列は，常在度を算用数字 (出現地点数) で印字する**．頭の数字は調査区数を超えない．
  表頭に `調査区数` (`Zahl d. Aufnahmen`) の行があれば，`to_csv.py` はその列の算用数字を出現地点数として読む．
- 常在度: V = 81-100%，IV = 61-80%，III = 41-60%，II = 21-40%，I = 1-20% の地点に出る．
- **地点の列の間に常在度の列が混ざる表がある** (調査区数を下線で示す)．値は `V(+-2)` の形で，括弧が上，ローマ数字が下の 2 段に組まれる．
  **行はローマ数字の高さで決める**．括弧はそのすぐ上に載り，隣の行の値に見える．重なりを避けて右へずれていても，属するのはすぐ下のローマ数字．
  密な所は 3 倍に拡大して画数を数える．この列の出現種数は平均値なので照合しない．
- コケ層の値が出現の印 `O` だけの表がある．`O` のまま書く (`cover` は `O`)．

### 階層

| 記号 | 層 |
|:---|:---|
| `T1` `B1` (`B`) | 高木層 (第 1 層) |
| `T2` `B2` | 亜高木層 (高木第 2 層) |
| `S` (`S1` `S2`) | 低木層 |
| `K` `H` (`K1` `K2`) | 草本層 |
| `M` | コケ層 (添字は付かない) |

- `B` は独語の Baumschicht．日本語の資料でも `B1` `B2` が多い．**印字のまま**書く (`B1` を `T1` に替えない)．
- **同じ種が階層ごとに別の行**になる．学名・和名は最初の行にしか無く，続く行は階層と値だけ
  (種名の欄が空)．空の行には**上の行の種名を引き継ぐ**．
- `S, K` のように 1 つの欄に 2 つの階層が書かれ，片方に下線が付くことがある
  (`S, K̲`)．**下線の付いた値は下線の付いた階層，下線の無い値はもう一方の階層**という組み方が多い
  (日本植生誌の本文・付表で確かめた)．扱いは次の 2 通り．
  - その資料で組み方が一貫している (下線の階層と下線の値が数行とも対応する) なら，
    **階層ごとの 2 行に分けて**転記する．分けたことと根拠を reading_log.md に書く．
  - 一貫しているか確かめられないときは `layer` に `S;K` と書く．`status` は `multi`
    (値は確かだが階層が決まらない) になり，下線の付いた値は note に書く．
  - 階層や値と同じように，**種名に下線を引いて対応させている可能性もある**．種名に下線があれば，何と対応するかを確かめて note に書く．決められなければ推測しない．
- `群落区分` が 2 段になることがある (`b` の下に `b1` `b2` `b3`)．上の段は `群落区分`，
  下の段は `下位群落区分` の 2 行に書く．

## 4. 表の下の文章

### 1 回出現の種 (`出現1回の種 Außerdem je einmal in Lfd. Nr. …`)

地点が 1 つの表には無い (全種が本体にある)．

1 地点にしか出ない種は，表を小さくするために本体から外して**文章で並べる**．
**本体と同じ情報なので，必ず取り込む** (`source` = `once`)．

```
出現1回の種 Außerdem je einmal in Lfd. Nr. 1: Artemisia princeps ヨモギ 1・2,
Robinia pseudoacacia ハリエンジュ +, in 2: Glehnia littoralis ハマボウフウ +, in 3: …
```

- 地点の変わり目は `in N:` (`Lfd. Nr. N:`)．**ここを読み違えると後ろが全部ずれる**．
- 種の区切りはカンマ．1 項目は「学名 和名 (階層—)値」．
  - 階層なし: `ヨモギ 1・2` → cover `1`，sociability `2`
  - 階層つき: `タカノツメ B2—+` → layer `B2`，cover `+`
  - 階層が複数: `ヒメドコロ S—+, K—+` や `リョウブ B2—1・2, S—1・2, K—+`
    → 階層ごとに別の行
- 行末で種名が割れる (`ハリ` / `エンジュ`，`Rhododendron` / `weyrichii`)．つないで書く．
- 列挙のあとに注記 (`Lage d. Aufn. 調査地`) が続く．そこから先は 1 回出現の種ではない．

段落の読み方の注意:

- **`in N:` の見出しが印字から欠けたり，2 回印字されたりする**．種は印字の段落のまま残し，`status=check` と note に候補の地点を書く．種数に合わせて動かさない (`check.py` の `[手がかり]` が候補を出す)．
- `in N:` の見出しを 1 つ前の地点に付けやすい．段落の見出しを全部並べ，once.tsv の地点の並びと比べる．
- 段落が 2〜3 段組のことがある．左の段を読み切ってから右の段へ進む．段の末尾の学名が，次の段の頭の和名に続く．右の段は表より右へ伸びるので，切り出しの右端に注意する．
- 紙面の貼り合わせの筋が段落を横切り，名前が欠けることがある．印字どおり書き，note に残す．

### 注記 (調査地・調査年月日・出典)

```
Lage d. Aufn. 調査地: Lfd. Nr. 1, 3: Sample-cho, Sample-gun 〇〇郡〇〇町 (6. Juli 1983), 2, …
Datum d. Aufn. 調査年月日: 22. Mai 1983.
Nachweis d. Vegetationsaufnahmen 既発表資料名: Lfd. Nr. 1, 3〜5: Original 原調査資料, 2: …
```

- `Lfd. Nr. 1, 3:` のように**複数の地点に 1 つの値**がかかる．地点ごとに行を分けて sites.csv へ．
  `3〜5` `3-5` は範囲．
- 日付は独語の月名が多い (Jan. Feb. März Apr. Mai Juni Juli Aug. Sept. Okt. Nov. Dez.)．
  英語の略記 (`6 Nov. 1973`) もある．
  `YYYY-MM-DD` にし，印字は `value_raw` に残す．
- 地名はローマ字と漢字の両方がある．`value` には漢字の地名を，`value_raw` に全体を書く．

### 本文・図・写真

組成表の上下に**本文** (群落の説明)・**写真**・**図の説明** がある．どれもデータではないので読まない．
ただし本文と表の下の文章は見た目が似ている．**形ではなく中身で見分ける**
(`出現1回の種` `Außerdem` `Lage d. Aufn.` `調査地` `Nachweis` で始まるかどうか)．

## 5. 紙面の型

| 型 | 見分け方 | 読み方 |
|:---|:---|:---|
| 1 段の表 | 種名の列が 1 本 | そのまま |
| **2 段組 (折り返し)** | 種名の列が左右に 2 本．**表頭は 1 つ** | 1 つの表の続き．右の段も同じ地点．右の段は左の段と同じ高さから始まる |
| 1 ページに表が 2 つ | 表題 (`Tab. N`) が 2 つ．種名の列ごとに表頭がある | 別の表として `table` を分ける |
| **ページ内の小さい表** | 本文・写真の間に数地点の表．表頭が無いか，文章の形のことがある | 表題から表の下の注記までを切る (`crop.py --zoom 2`)．地点の情報は注記から取る．出現種数が無ければ，種の数を数え直す |
| **折り込み** (A0 級) | 1 枚に 2〜5 表．隅の札に `Tab. 12, 13, 14.` と載る | 表ごとに切り出してから読む．札の表の数と合わせる |
| 横倒し | 種名が下から上 (または上から下) に並ぶ | 起こしてから読む (`scripts/crop.py --raw --rotate`) |
| 続きのページ | 表の下の文章が次のページにあふれる | ページをつないでから読む (SKILL.md の手順 2) |

- 2 段組では表頭の種数が「本体の左右の段 + 1 回出現」で合うかを見る．
- 2 段組の右の段の頭に見出しが無ければ，左の段の最後の見出しの続き．
- 地点の少ない表では，**表頭が無く，地点の情報が表の下の注記にだけある**ことがある．

### 地点の間に常在度の列が混ざる表

- 地点の列の間に，常在度の列 (調査区数を下線で示し，値は `(+-2)` と `V` のように上下 2 段，または `III(+-2)` の形) が混ざる表がある．
- その列だけ値が広く，**列の間隔が等間隔でない**ので，`crop.py --dense` の列の測定が効かない (等分に落ち，札が 1 列ずれる)．
- 地点の列の組と常在度の列を分け，その列だけ広く切るタイル (列の組と y の帯を指定) を作って読む．
  列の中心を投影で測り，帯ごとに地点番号と案内線を重ねた合成画像にすると，右端の行ずれも防げる．
- 地点が多く，群ごとに隙間がある表も同じ扱い．
