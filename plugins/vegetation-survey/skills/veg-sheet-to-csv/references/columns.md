# 列の定義 (植生調査資料DB形式，47 列)

1 行が 1 つの種．地点の列 (0〜36) は同じ調査地点の全行で同じ値になる．
`scripts/build_csv.py` の `SITE_COLS` と `SPECIES_COLS` がこの表と同じ順．

| 番号 | 列名 | 内容・例 |
|---|---|---|
| 0 | 資料調査番号 | 資料ごとの調査番号．調査票に無ければ空欄 |
| 1 | 調査票No | 資料内の調査票の番号 |
| 2 | 調査地点No | 地点の番号 (例 XX29) |
| 3 | 調査年月日 | `YYYYMMDD` (例 19990621) |
| 4 | 調査者名 | 複数は読点で区切る |
| 5 | データ公開レベル | 既定 `公開` |
| 6 | 国コード | 既定 `日本国` |
| 7 | 都道府県 | 例 ○○県 |
| 8 | 市郡町村区名 | 例 ○○市 |
| 9 | 以下 | 市郡町村区より下の地名 (例 ○○山) |
| 10 | 緯度 | 10 進度 (例 35.12345) |
| 11 | 経度 | 10 進度 (例 135.12345) |
| 12 | 地点精度 | コード (意味は不明．調査票に無ければ空欄) |
| 13 | ３次メッシュコード | |
| 14 | 地形条件 | 例 斜面下，尾根 |
| 15 | 斜面方位 | 例 N10E，N40W |
| 16 | 傾斜角度 | 度 |
| 17 | 標高 | m |
| 18 | 面積1 | m (調査区の一辺) |
| 19 | 面積2 | m (もう一辺) |
| 20 | 面積測定方法 | コード．見本は 0 |
| 21 | 被度の評価方法 | コード．見本は 0 |
| 22 | 群落名 | 例 シイ-カナメモチ群集 |
| 23 | 備考 | 列の無い項目 (風当・日当・土壌・土湿・図幅) をここへ |
| 24 | 高木層階層高 | m |
| 25 | 高木層植被率 | % |
| 26 | 亜高木層階層高 | |
| 27 | 亜高木層植被率 | |
| 28 | 第1低木層階層高 | |
| 29 | 第1低木層植被率 | |
| 30 | 第2低木層階層高 | |
| 31 | 第2低木層植被率 | |
| 32 | 第1草本層階層高 | |
| 33 | 第1草本層植被率 | |
| 34 | 第2草本層階層高 | |
| 35 | 第2草本層植被率 | |
| 36 | コケ層植被率 | |
| 37 | 行番号 | 空欄でよい |
| 38 | 階層 | T1 高木層，T2 亜高木層，S1 第1低木層，S2 第2低木層，H1 第1草本層，H2 第2草本層，M コケ層 |
| 39 | 種名 | 半角カナ (見本) か全角カナ |
| 40 | 種名（公開用） | 種名と同じ (希少種を伏せるときだけ違う) |
| 41 | 科名 | 空欄でよい |
| 42 | 学名 | 例 Castanopsis cuspidata |
| 43 | 被度階級値 | 例 5，4，3，2，1，+ |
| 44 | 群度 | 1〜5．`+`・`r` だけのときは 1 を入れる |
| 45 | 被度百分率 | 調査票が % で書いているときだけ |
| 46 | 絶滅危惧種フラグ | 0 / 1．既定 0 |

## 階層の読み替え

調査票の階層名はいろいろある (B1・B2・K や，高木層・亜高木層・低木層・草本層)．
階層ごとの高さと植被率の表を見て対応させる．よくある対応:

| 調査票 | DB | 備考 |
|---|---|---|
| B1，高木層 | T1 | 高木層階層高・植被率に入る |
| B2，亜高木層 | T2 | |
| S1，第1低木層，低木層 | S1 | 低木層が1つだけなら S1 |
| S2，第2低木層 | S2 | |
| K，草本層 | H1 | 草本層が1つだけなら H1 |
| コケ層 | M | 植被率だけ地点の列に入れる |
