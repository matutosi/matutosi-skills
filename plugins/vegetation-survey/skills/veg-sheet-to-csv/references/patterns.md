# 調査票のいろいろなパターン

ネット検索 (環境影響評価書・大学の紀要・環境省の調査マニュアルなど) で確かめた，調査票の書き方の違い．
実物の調査票は上の表どおりとは限らないので，**最初に1枚見て，どのパターンかを決めてから読む**．
**確かめた出典は [出典](#出典) にある．実際の様式は調査主体ごとに違うので，ユーザから入力と出力の例をもらうのが確実．**

## 1. 被度・群度の書き方

| 調査票の書き方 | 例 | CSV への入れ方 |
|---|---|---|
| ブラウン-ブランケの被度・群度を「被度・群度」で併記 | `3・4`，`3.4`，`3,4`，`2-2` | `被度・群度` に書く．被度階級値と群度に分かれる |
| 被度だけ (群度の欄が無い) | `3` | 被度階級値のみ．群度は空欄／NA |
| `+` や `r` | `+`，`r` | 被度階級値にそのまま．`r` を使う調査票は `r` を残す (`+` に丸めない) |
| 被度が % (百分率) | `35`，`<1` | 被度百分率に書く．被度階級値は調査票に無いので空欄 (換算は頼まれたときだけ，下の表) |
| 総合優占度 (SDR など) や Domin 階級 | `D5`，`7` | 被度階級値にそのまま入れ，備考に「被度は Domin」と書く．ブラウン-ブランケと混ぜない |
| 活力度 (生活力) が付く | `3・4(2)` | 括弧は活力度．列が無いので備考か捨てる (ユーザに聞く) |
| 個体数だけ・出現の有無だけ | `○`，`3` | 有無なら被度階級値に `+` を入れず，備考に「在不在のみ」と書き，被度は空欄／NA |

ブラウン-ブランケの被度階級の目安 (出典の長野県資料による): 5 は 3/4 以上，4 は 1/2〜3/4，3 は 1/4〜1/2，2 は 1/10〜1/4 (または個体数が非常に多い)，1 は 1/10 未満，`+` は個体数も被度も小さい，`r` は極めてまれ．
群度は 5 (カーペット状に一面) 〜 1 (単独) の 5 段階．

## 2. 階層の書き方

| 調査票の書き方 | 対応 |
|---|---|
| 高木層・亜高木層・低木層・草本層 (4 層) | T1・T2・S1・H1．低木層は S1 (層が1つなら) |
| 高木層・亜高木層・低木層・草本層 1・草本層 2 | T1・T2・S1・H1・H2 |
| B1・B2・S1・S2・K | T1・T2・S1・S2・H1 (B=Baum，K=Kraut) |
| 第1〜第4層 などの番号 | 階層ごとの高さの表を見て，高さの順に T1・T2・S1・H1 に当てる |
| 階層の区別が無く，種のリストだけ | `階層` は H1 にせず空欄／NA にして備考に書く．ユーザに確かめる |
| 同じ種が複数階層に出る | 階層ごとに1行 (被度もそれぞれ) |
| コケ層・地衣層 | M．種ごとの行は作れるが，植被率だけの調査票もある |
| 階層の高さ・植被率は欄が層ごとにあり，高さが `~`・範囲で書かれている | 範囲なら平均を入れず，備考に範囲を書き，階層高は上限を入れる (ユーザの指示があればそれに従う) |

## 3. 地点・環境の書き方

| 項目 | 注意 |
|---|---|
| 調査年月日 | 和暦・`R3.6.21`・`2021/6/21` → `YYYYMMDD`．年が2桁で世紀が不明なら，調査者の活動期間などから推定せず空欄にして報告 |
| 面積 | `10×10m`・`100㎡`・`10m²` のどれか．`100㎡` のように1つだけなら面積1 に入れ，面積2 は空欄 (一辺を平方根で創作しない) |
| 方位・傾斜 | `N40W`，`北西`，`NW`．方位は調査票どおり．傾斜は度か `%` かを確かめる |
| 緯度経度 | 度分秒 → 10進度に換算してよい．ただし換算した旨を備考に書く．座標系 (日本測地系か世界測地系) が分かれば備考に書く |
| 地名 | 調査票のとおり．合併・改称は直さない |
| 標高 | m．`約120`・`120±` は数だけ |
| 調査者 | 複数は読点区切り．所属は入れない |
| 備考 | 風当・日当・土壌・土湿・図幅・林齢・林床の様子・撹乱など，列の無い項目 |

## 4. 種名の書き方

- 和名のカナ (全角・半角)・漢字・学名・略号・属名のみ (`スゲ属`)・`sp.` のいずれもある．**調査票のとおり読み，分からない種は無理に種名にしない** (属名や `Unknown` に)．
- 学名が調査票にあれば，それを使う (和名から付け直さない)．
- **似た種で迷うものは，形態の情報 (葉の対生・互生，複葉か) が書かれていれば根拠にする**．
- 種名の末尾の `?`・`cf.` は消さず備考に残す (種名の列は同定の確かなものだけにする)．

## 5. 調査票の形式

| 形式 | 読み方 |
|---|---|
| 1 枚 = 1 地点 (相観・階層ごとに種を並べる) | 標準．階層ごとに読む |
| 組成表 (行 = 種，列 = 調査区) | 列ごとに1調査区として，調査区の数だけ sheet を作る．調査区の番号は `調査地点No` へ．常在度・区分種の欄は読まない |
| 複数ページ (表の続き) | 地点情報はページ1のものを使い，種の表だけ足す |
| 手書きの表 | 字が小さいので切り出して拡大する．読み取りの確信が低い行は報告に書く |
| 縦書き・方眼 | 90°回して読む |
