## やること

**書き直し案を3つ**出してください。3つは**互いに違う直し方**にすること
(語を替えるだけの3案は意味がない。語順を変える案・文を割る案・削る案、のように
アプローチを変える)。そのうえで、次の3つの軸で1〜5点を付けて自己採点します。

| 軸 | 何を見るか |
| --- | --- |
| 正確さ | 元の主張・数値・参照を変えていないか。事実を足していないか |
| 収まり | 前後の文とつながるか。用語が原稿の他の箇所と揃っているか |
| 読みやすさ | 一読で分かるか。冗長でないか |

**採点の基準を言葉にしてから点を付ける**(1点: 明らかに不適切 / 2点: 不十分 /
3点: 許容範囲 / 4点: 良好 / 5点: 申し分ない)。

## 出力の形式(厳守)

```
### 案1
- after: <置換後の1行全文>
- 正確さ: <点> / <理由1行>
- 収まり: <点> / <理由1行>
- 読みやすさ: <点> / <理由1行>

### 案2
(同じ)

### 案3
(同じ)

### 推奨
- 採る案: <1|2|3>
- 理由: <1行>
- 3案とも3点以下の軸があるか: <ある|ない>
```

**3案とも3点以下の軸があるときは、その旨をはっきり書く。**
無理に1つ選んで「推奨」とだけ書かない。原文のままのほうが良いこともある。
