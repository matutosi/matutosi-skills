# 第1章 植生データの準備 {#ch-data}

## 1.1 植生調査とデータの形

植生調査では，調べる場所に**方形区**(コドラート)を置き，出現した種を記録します．
種ごとに**被度**を記録しておけば，種の多さだけでなく，量も解析に使えます．
調査地点を行，種を列にして被度を並べた表を，**組成表**といいます．
R の ecan パッケージは，この組成表を入力にして，序列化やクラスタリングを行います．

## 1.2 縦長の表と横長の表

ecan では，群集のデータを2つの形で扱います．
1つは地点・種・被度の3列からなる縦長の表で，もう1つは組成表です．
2つの形は，table2df() と df2table() で相互に変換できます．
ordination() や cluster() は組成表を，shdi() や ind_val() は縦長の表を受け取ります．

## 1.3 データを読み込む

CSV ファイルの組成表は，read.csv() で読み込み，1列目を行名にします．
調査支援システムの BiSS から出力した JSON は，read_biss() で読み込めます．
読み込んだら，種数と地点数を確かめ，被度がすべて数値になっているかを見ておきます．
方形区の面積が地点ごとに違うときは，群集の比較に使えるかを先に考えます．

## 1.4 解析の見取り図

この本では，ecan を使って，次の3つの解析を順に学びます．
- 序列化: 地点を，種組成の似かたに応じて並べる
- クラスタリング: 地点を，種組成の似たものどうしにまとめる
- 多様度と指標種: 種の多様さや，群落を特徴づける種を調べる

どの解析でも，群集の類似度を測るために距離を選びます．
