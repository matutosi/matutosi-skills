# 第2章 序列化 {#ch-ordination}

## 2.1 序列化とは

種組成の似た地点を近くに，違う地点を遠くに置いて，地点を低次元の図に並べる方法を**序列化**といいます．
ecan では，ordination() に組成表と手法の名前を渡します．
手法には，PCA，CA，DCA，PCoA，NMDS が使えます．
結果は ord_plot() で図にします．

## 2.2 距離の選び方

被度のデータには，ブレイ・カーティス距離がよく使われます．
PCoA や NMDS は，地点どうしの距離から図を作るので，距離の選びかたが結果を左右します．
**ユークリッド距離**は，PCA の背後にある距離で，種の量の差をそのまま反映します．
distance() は，距離の名前を渡すだけで，距離行列を返します．

## 2.3 DCA と NMDS

**DCA** (除歪対応分析)は，対応分析の弓なり効果を取り除いた手法です．
軸の長さが，地点の入れかわりの大きさの目安になります．
**NMDS** は，地点間の順位を保つように点を置く手法で，距離の種類を選べます．
NMDS では，点の配置が乱数の初期値で変わるので，結果を再現するには種を決めておきます．

## 2.4 結果を読む

図の上で近い地点は，種組成が似ています．
ただし，軸の向きそのものには意味がありません．
ord_add_group() で環境や土地利用の区分を加えれば，群集の違いを色分けで確かめられます．
距離の選びかたを変えたら，図の見えかたがどう変わるかも確かめてください．
