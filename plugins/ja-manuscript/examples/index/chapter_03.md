# 第3章 焼成と保存 {#ch-baking}

## 3.1 焼成

二次発酵を終えた生地を，予熱したオーブンで焼きます．
この工程を**焼成**といいます．
焼成温度の目安は，食パンで約200℃，ロールパンで約190℃です．
焼きあがったら，すぐに型から出して網の上で冷まします．

## 3.2 焼きあがりの確認

底を軽くたたいて，乾いた軽い音がすれば焼きあがりです．
色が薄いときは，オーブンの火力が足りない可能性があります．
生地の酸性度は pH で表します．
発酵が進みすぎると，pH が下がって酸味が出ます．
酵母が働きすぎないよう，温度管理を続けてください．

## 3.3 保存

粗熱がとれたら，ポリ袋に入れて常温で保存します．
2日以上おくなら，1枚ずつラップで包んで冷凍します．
食べるときは，凍ったまま焼くと，ふんわり仕上がります．

## 3.4 失敗の原因

焼きあがりが小さいときは，発酵が足りないか，酵母が古い可能性があります．
気泡が大きいときは，パンチでガスを十分に抜けていません．
表面に割れが出るときは，二次発酵の不足か，オーブンの温度が高すぎます．
どの場合も，温度管理の記録を残すと，原因を探しやすくなります．
