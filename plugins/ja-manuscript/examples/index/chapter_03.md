# 第3章 分類と多様度 {#ch-classification}

## 3.1 クラスタリング

種組成の似た地点をまとめて，群落に分ける方法が**クラスタリング**です．
ecan では，cluster() に組成表，結合の方法，距離の名前を渡します．
結合の方法には，ウォード法や群平均法などがあります．
ウォード法は，まとまりの大きさがそろいやすく，群落の分類によく使われます．

## 3.2 樹形図

クラスタリングの結果は，**樹形図**で見ます．
枝の高さは，まとまる時点の距離を表します．
cls_add_group() で，各地点に群落の区分を添えると，ラベルが読みやすくなります．
どこで切るかは，生態学的な解釈を見ながら決め，機械的には決めません．

## 3.3 多様度

群落ごとの種の多様さは，**多様度**で比べます．
shdi() は，種数のほかに，シャノン指数とシンプソン指数を返します．
**シャノン指数**は，まれな種の寄与が大きく，**シンプソン指数**は，優占種の寄与が大きくなります．
どちらも，群集の距離と同じく，被度のデータから計算できます．

## 3.4 指標種

群落に特徴的な種を探すには，**指標種**分析を使います．
ind_val() は，群落の区分と縦長の表を受け取り，種ごとに指標値を返します．
指標値が大きい種は，その群落に偏って出現し，かつ，群落内で広く出現する種です．
指標種が妥当かどうかは，クラスタリングの結果と，序列化の図を並べて確かめます．
